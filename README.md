# Kiwassa Connect 
An app designed to help Kiwassa Residence residents communicate, find information, and stay connected with their building and each other.

## Getting Started

### Prerequisites
- Next.js
- Firebase
- Vercel

### Installation
- bash
- git clone https://github.com/ShayJah/residence_app/

### Deployment
npx expo start


## Built With
Frontend: Next.js (React)


Backend: Firebase or Supabase


Deployment: Vercel
